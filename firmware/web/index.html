Board

Green: all good · amber: MQTT not connected · blinking blue: setup access point · blinking red: no network. Flashes white when a relay switches.

Modbus RTU (RS485)

Firmware update

Upload build/waveshare-relay-firmware.bin. If the new firmware fails to start, the device rolls back to the current one automatically.

Admin password

Maintenance

Factory reset erases Wi-Fi, MQTT and all other settings. Holding the BOOT button for 5 seconds does the same.

Relays in the same group are never on together. Switching one on turns the others off first, with a short pause, e.g. for motor up/down.
